# 独立设计调整说明

版本：0.6 · 2026-10-19 · 适用：本次调整后的门派、战斗、地图、养成与 UI。

## 1. 目标与保留内容

保留用户已经确定的五角色五宠、指令式回合战斗、角色最高 175、术式最高 180、宠物培养、装备打造、NPC 帮派和买断制单机目标。

本次改变玩家的决策、系统关系、区域职责和内容组织，减少对单一参考作品的逐项对应。不是通过删除参考记录或只替换名词获得“原创认证”；原有 Git 历史保留。

## 2. 实质变化

| 旧版设计轮廓 | 新版实现方向 | 玩家实际变化 |
| --- | --- | --- |
| 三段连击＋血线门槛＋强制休息 | 执衡的标记、下一轮换序与人宠协作 | 思考队友时序与标记投入，普通下一回合仍能行动 |
| 变身后群攻／连击再休息 | 百骸的耐久设施、骨片和拆解 | 为进攻主动放弃防护，共享设施槽形成选择 |
| 固定目标数持续群法 | 听潮的水路连接与伤害／资源分流 | 先选择端点，输出与治疗共享路径准备 |
| 高速、双封、暗器固伤和毒组合 | 绛罗的意图公开、诱饵和目标偏引 | 根据锁定意图布置防护，不阻止对方整回合 |
| 睡眠、分类封印与降防 | 绘契的条件条款与兑现 | 敌人能选不同指令避开触发，牵制有可见反制 |
| 固定人数群疗与物理增益 | 济世的医签、延迟伤害和总治疗预算 | 按缺血分配固定总量，有限救援资源 |
| 持续三跳回血、复活和法术增益 | 照灯的记录、有限储能与转移／净化 | 同一份灯能只能在几种用途之间选择 |
| 七轨与统一主修门槛 | 六轨独立修习 | 无主修强制带动其余技能，费用按六轨计算 |
| 固定等级的三段突破链 | 并行地区契约与互斥队伍誓约 | 探索与地方结局打开横向能力，不控制数字等级上限 |
| 主城—国境—边荒—远村及海外直通北域 | 双河水陆网、海陆商路与两个终局入口 | 从行旅枢纽选择路线，城市非必经中心，任务可改变捷径 |
| 泛化经典木框金边 UI | 靛蓝行旅册、朱砂印签与五组人宠对签 | 从信息结构到主视觉为新机制服务 |

## 3. 设计约束

不得在当前设计中恢复一张原作门派对照表后仅改名；增加招式时先写清用途、准备、代价、反制和与其他系统的关系。不能重新凑回旧的整组技能循环。

地图以当前交通数据为准，地区故事和资源职责与旧关系独立。新增地图不要先寻找一个参考地图的一对一替身。界面也不追摹参考截图的精确布局或专有装饰。

术式与费用可以保留自拟参数，但不能用改几个倍率、改等级数字或改文案作为主要差异证据。保留设计草稿、素材授权和实际测试结果，不篡改开发记录。

## 4. 验证与剩余工作

工程检查验证文档、数据及依赖；设计一致性检查验证地图连通、六轨结构和费用口径。它们不能代替玩法测试、素材相似性比对或法律审查。

当前没有完成可玩战斗和正式美术，因此不能断言成品不会侵权。上线宣传、商标、角色、UI 资产、剧情文本及发行地区需要结合实际版本审查。

法律依据的范围：法院公开案例区分玩法机制与具体表达，同时从模仿程度、竞争利益与商业道德等方面分析不正当竞争；不存在换名或修改到某个百分比就安全的通用标准。[法院案例解析](https://www.court.gov.cn/zixun/xiangqing/463511.html)

宣传需建立独立名称和定位，避免引人误认为存在授权或合作关系。[反不正当竞争法](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_3737890d856a4e44a8ea07c50c90c116.html)
