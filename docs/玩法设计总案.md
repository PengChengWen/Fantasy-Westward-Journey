# 《照夜山海》玩法设计总案

版本：0.6 · 2026-10-19 · 原创方向调整稿，待原型验证。暂定名称与标识仍需发行前检索。

本作是 Steam 买断制离线单机，玩家经营五名照夜人的行旅队伍，每人可带一只灵兽。核心乐趣是回合战术、伙伴成长、区域探索、工艺打造和行会经营。角色最高 175 级，术式最高 180 级；Q 版国风采用本项目自己的角色造型、布局和视觉语言。

独立设计原则与旧稿差异见 [独立设计调整说明](独立设计调整说明.md)。本作不以既有产品的七派、地图、进阶链和视觉逐项对应作为制作模板。当前只有工程骨架，以下系统均为设计目标。

## 1. 世界与主线

地契记录着水源、商路和居民记忆之间的约定。连续灾害使旧地契失效，不同聚落对修复方式产生分歧。照夜人受托携灯查验、组织工程并保存证词，最终决定如何重建共同生活的规则。矛盾来自资源、责任和记忆，不采用固定的三界阵营晋升故事。

三个地区的地契调查可以交错推进。每条线的多种决议均能完成主线，带来配方、关系、路线和战术选项差异，不是必须按顺序突破的三道境界。终局有水路与陆路两个入口，角色未满 175 也能尝试；完整流程见 [世界地图与区域设计](世界地图与区域设计.md)。

## 2. 日常游玩循环

20—30 分钟的一次旅途包含：选择地区委托 → 收集证词与勘测 → 一至三场战斗或环境挑战 → 决定处理方案 → 领取经验、铜铢、材料与地区反馈 → 调整术式、灵兽和装备。存档点、任务列表与收益预览支持随时安排，不以在线时长、真实日历或重复签到约束进度。

中期目标是让队伍形成能应对不同地形和敌人意图的组合，再以配方、亲本共育、行会工程和可选远征扩展选择。装备极品、稀有灵兽和六轨全满属于长期目标，普通培养也应可通关。

## 3. 编成与战术门派

五名角色各有自己的在场灵兽；十个单位独立行动。角色换宠占主人行动，新宠下回合行动。没有通过队列交换、设施或复活无限增加行动的机制。

| 门派 | 战术中心 | 玩家主要决策 |
| --- | --- | --- |
| 执衡院 | 衡印与下回合换序 | 先校势蓄印，还是提前安排救援顺序 |
| 百骸谷 | 可拆骨垒与骨片 | 用两个公共设施位保人，还是拆垒形成攻击预算 |
| 听潮阁 | 一条双端水路 | 连接敌人分流，还是连接友军分享治疗与真气 |
| 绛罗坊 | 公开敌方意图与幻饵 | 侦察哪次行动、让哪一段攻击被偏引 |
| 绘契司 | 两份条件契约 | 限制对手的收益，还是主动兑约结束等待 |
| 济世院 | 医签、待伤和共享分诊 | 延后压力后何时偿还，如何分配有限治疗预算 |
| 照灯坊 | 有储能上限的气血记录 | 为谁存照，何时回补，何时消耗灯解控 |

每派五条主动研修轨和一条专长轨，各自付费升级，取消主功法统领其余功法的层级结构。上限 min(180,角色等级+5)，不另设境界门槛。35 个主动术式的解锁、系数、真气、冷却、驻地与逐级费用统一见 [门派设计](门派设计.md)，结算见 [战斗系统设计](战斗系统设计.md)。

## 4. 异象调查与委托

调查以“现场线索—提出判断—采取措施—结果回访”为核心。潮汐异常可能来自旧闸故障、居民迁居或灵兽活动，不是每次遇到怪物就直接消灭。任务可选择安置、修复、护送、谈判或战斗；不同方法获得同量主线进度，材料侧重不同。

可重复委托由地区问题池组合地点、事件和目标；连续完成不形成固定十环怪物追杀链。奖励按时间与危险度预算，不以必须带某个门派才能高效刷取为常态。重复委托不能覆盖已经写入的主线决议。

## 5. 秘图、考古与远征

普通勘测图给出地貌与证词线索，玩家实地定位、校对路径后发现小遗迹；可标注后稍后返回，不强迫消耗即开随机宝箱。高级秘图是多地点组成的考古项目，需要调查许可、工具、风险选择与分段撤离。

远征结算以带回的样本和完成的研究目标为主，可消耗补给选择更深层探索。稀有奖励使用清楚的掉落范围和保底研究进度，不能因中途退出抹掉已安全带回的进度。地图、谜题、事件脚本和奖励表均重新创作。

## 6. 灵兽捕捉与亲本共育

不同生态位有食物、习性和战斗倾向，捕捉包括观察、准备诱引与战斗中的安抚，不要求压到固定血线后无限掷道具。每名角色最多一只在场灵兽；后备灵兽存于营舍。

亲本共育保留两只亲本，消耗研究材料和时间步数生成一只后代；步数由冒险结算推进，不依赖现实等待。先选一项目标性状，再从明确的遗传池抽取其余特征。最多六个技能位，重复标签合并规则、技能冲突和概率都提前显示，允许在确认前查看材料总价。

稀有守契灵兽来自地区生态修复和独立支线，价值在独特的战术与外观，而非通关必要的全面高属性。造型、命名、动作、图标、技能与获取剧情独立制作。

## 7. 打造与工艺

打造分为材料、工法、灵性三步：材料决定基础区间，工法决定结构与一项可控偏向，灵性提供有限随机词条。玩家可预览基础范围、冲突词条与保底进度；不得照搬现有产品的等级装备表、伤害公式、特技表和强化成本。

装备提供稳定属性与少量战术标签，避免所有随机收益只追同一最优词条。旧装可拆解返部分材料；同一构建不需要追齐稀有词条才成立。打造、共育和领取订单均为一次事务，材料不足不部分扣除，重复点击不重复发奖。

## 8. 行会经营

玩家管理的是照夜行会驿站。招募 NPC 分配修路、研究、照料和护运岗位；派遣进度由冒险结算推进。出战成员不能同时占用派遣岗位，不能通过现实时间快进反复结算。

建筑重点为工坊、兽舍、档案室和仓站，分别解锁工法、共育研究、证词检索与路线补给。地区工程改变交通和订单，不只是单线捐款换被动属性。所有必要设施有主线可达的基础版本，经营可以拓宽选择，不强迫刷贡献才能学核心技能。

## 9. 公开赛会

金照赛会为离线 NPC 队伍赛事。报名时显示赛程、敌方风格和场地规则；玩家提交参赛队伍，在回合制规则内挑战。每轮从公开的两项场地议题中选择一项，如设施耐久变化或补给限制；对双方同等生效，不暗改敌方命中。

赛制采用分组积分后淘汰，可在局间调整后备编成；退出保留已完成场次。奖励为称号、外观、战术配方和可重复获取的资源，不用唯一永久战力逼迫玩家参加。名称、界面、报名流程、奖杯与主持剧情独立设计。

## 10. 副本与长期成长

副本为本世界的问题解决远征：沉船修复、矿洞支架、旧库证词、风缆试验和归墟救援等。每个副本有自己的环境规则和可带回成果；战斗之外允许勘测与工程选择，不能只按旧产品副本流程换文案。

角色 1—175、六条术式 0—180、装备工法、灵兽共育、地区地契、行会工程分别保存。角色经验与修业经验分开。地区决议提供侧向收益，不抬角色等级上限，也不构成固定飞升、渡劫、化圣的顺序链。

单轨升级曲线保持本项目自拟版本，六轨角色全满 40,534,860 修业经验和 14,192,160 铜铢；五人共 202,674,300 和 70,960,800。点满时间只是后期收益预算参考，不作为通关时长承诺；完整 180 行由脚本生成，不能手改累计值。

## 11. 美术与内容来源

UI 采用“靛蓝行旅册、朱砂印签、折纸与铜铆钉”的独立视觉语言，五组人宠对签、设施边栏与指令册页形成信息结构；详见 [UI设计与生成规范](UI设计与生成规范.md)。Q 版是比例方向，不是指定产品的脸型、服装、画框和图标模板。

素材登记作者、原文件、授权与修改记录。不得提取其他游戏的客户端、音效、图标、地图或数值表用于生产；参考研究与自主草稿应分别留痕。正式标题、商标、商店文案及完成后的素材仍需发行前专项审查。

## 12. 开发顺序与范围

M0 验证 Godot .NET、规则工程、Windows 导出和本地存档；M1 先普通攻击、五人五宠与一个标记机制，再逐个加入七派对象；M2 完成青禾埠、双河驿、芦汀原、听潮湾、断桅礁五区闭环；M3 加入工艺、共育、行会与公开赛会；M4 完成并行地契和双入口终局；M5 完成发行与素材审核。

地图图谱、技能数值和 UI 规范是可复核规格，不代表对应玩法已经实现。工程与检查方式见 [整体架构与目录设计](整体架构与目录设计.md)、[开发环境与工程检查](开发环境与工程检查.md) 和 [技术选型方案](技术选型方案.md)。
