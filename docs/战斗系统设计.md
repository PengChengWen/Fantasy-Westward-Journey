# 回合制战斗系统设计

版本：0.5 · 日期：2026-10-19 · 五名角色各带一只宠物，我方最多十个在场单位；角色最高等级 175，功法最高等级 180。

本文件维护指令、行动顺序、状态时序、宠物归属、首领抗控和通用计算。七派驻地、功法、具体招式效果及技能升至 180 级的消耗独立维护在 [门派设计](门派设计.md)，世界通行关系见 [世界地图与区域设计](世界地图与区域设计.md)。

本次只更新设计，不表示完整战斗系统已经实现。不同文档发生歧义时，通用时序以本文为准，具体招式数值与明确的特例以门派设计为准；需要同步修正歧义，不能各自实现一套规则。

## 1. 通用战斗规则

### 1.1 回合流程

1. 回合开始：显示气血、真气、封印、休息、变身、持续恢复等状态，给出已公开的敌方强招意图。
2. 下令：玩家配置五名角色与各自一只灵兽的行动，我方最多十条常规行动指令，可给伙伴与灵兽设置自动策略。角色与灵兽分别使用自己的速度和行动次数。双方在同一阶段确定指令，敌方不读取玩家尚未执行的指令。
3. 排序：按指令提交时的速度从高到低生成队列。同速使用战斗随机种子抽签；显示预估顺序。基础版不添加每回合速度随机浮动。
4. 执行：逐个检查存活、休息、封印、目标和资源，再结算技能。速度增减从下一回合排序起生效。
5. 回合末：结算毒与已到期的持续恢复，更新状态与冷却，判断胜负。复活单位从下一回合恢复行动。

基础版以速度排序为主；防御状态在自身行动时生效，需提前考虑速度。保护指令在提交时建立保护关系，保护者本回合消耗自己的行动，至回合末结束；休息、睡眠或专门禁止保护的状态下不能建立保护。封物理、封法术和普通双封本身不禁止保护。

指令类型：普通攻击、门派技能、防御、保护、道具、召回／召唤、撤退。场上每名角色最多对应一只灵兽，合计最多五只；不要求开战时必须带满。

宠物归属与替换规则：

- 战前指定每名角色的首发灵兽，首发随主人入场，不占首回合角色行动。同一灵兽实例不能分配给两名角色。
- 角色和灵兽分别下令、各有速度与状态。主人休息、被封印或倒地，不自动让已在场的灵兽停止行动；灵兽仍受自己的控制和存活状态限制。
- 召唤、召回或直接替换均由主人消耗一次角色行动；替换可在一次行动内让旧灵兽离场、新灵兽入场，不额外要求先花一回合召回。
- 新入场灵兽从下一回合开始行动，不能继承旧灵兽的待执行指令。旧灵兽离场时取消其尚未执行的指令；已完成的行动不回退。
- 主人倒地、睡眠或休息时不能召唤；封物理、封法术和普通双封只限制对应招式，本身不禁止召唤。召唤不作为法术招式。
- 灵兽倒地后可被符合目标条件的复活技能救起，或由主人替换；一旦被替换离场，不能再作为本场的在场复活目标。
- 每名主人只管理自己的在场位；替换前检查新灵兽未被其他角色使用。主人倒地不释放归属供其他角色重复调用。

五角色五灵兽改变编成容量，不自动把群攻或群疗目标数提升到十个；各技能仍按自己的目标上限结算。敌方数量由遭遇配置决定，比武原型至少覆盖双方各十个单位的完整场景。

### 1.2 通用属性与伤害

- 基础成长：体魄、力量、灵识、耐力、身法，分别侧重气血、物攻、真气与法攻、物防、速度。角色基础属性的精确转化公式尚未定稿；招式结算使用下文统一约定。
- 战斗属性：气血、真气、物攻、物防、法攻、法防、速度、封印命中、封印抵抗、治疗强度。
- 门派招式分物理招式、法术招式、恢复、增益、控制；“封物理”与“封法术”根据招式标签判断，不根据动画或是否消耗真气判断。
- 固定伤害由等级、技能熟练与指定辅助属性形成基础值，不经过普通物防／法防减算；仍受明确的减伤、护盾、免疫和首领规则约束，不是无条件真实伤害。
- 治疗效果不会默认对敌方造成伤害。复活不复原真气、不刷新冷却、不产生当回合额外行动。
- 本版门派技能使用真气；具体招式的功法等级、消耗、倍率和解锁条件见门派设计，当前均为待测试的初案。

### 1.3 状态时序

回合记作 R。技能声明、消耗、命中与状态日志应显示失败原因。

- 休息一回合：在 R 使用强招后，R+1 整回合无法主动操作，包括道具、保护、换宠与撤退；被动和接受队友治疗仍可生效。不能用解封解除休息。
- 冷却 C 回合：R 施放后，R+1 至 R+C 不可再次使用，R+C+1 可用；表中冷却 0 表示下一回合可再次使用。
- 兽相：施放后覆盖自己随后四次行动机会，休息也占一次；施放当次不占用四次机会。只有在行动执行检查时仍有兽相，强招才可施放。
- 持续治疗三次：先结算技能的即时治疗，随后在 R+1、R+2、R+3 回合末各结算一次，最后移除。重复施放刷新次数，不叠加相同来源的多条治疗。
- 普通增益三回合：当前回合生效，持续至 R+2 回合末。速度收益从下一回合开始体现；技能 UI 显示剩余结算次数。
- 封印的“两次行动机会”按目标的行动槽计算；封印在目标出手前命中，当回合即占一次；目标已经行动，则从下回合开始。不能通过用无效指令跳过消耗。
- 同一目标同时只有一个硬控状态；硬控期间再次施加不能延长剩余受控行动机会，更换硬控种类也必须继承原剩余次数。附带的普通降防可以按各自规则刷新，不能借此重置硬控时长。
- 目标在行动前失效：攻击可按预先设置转到合法敌方目标；治疗按策略转向合法友方。连击开始后不因击倒原目标自动转火；复活目标已存活则不消耗资源，并记录空过。
- 下令时与执行时均检查技能条件；因气血、变身或控制导致指令失效，不扣原技能资源，按已设置的合法替代指令结算；无替代指令时空过，不退还行动。资源在实际执行时扣除；封印未命中仍正常消耗。
- 非休息单位的无效指令按预先策略替代：受封物理可改为防御／道具，受封法术可改为普攻／道具。睡眠与休息不触发替代行动；不允许临时读取敌人未公开指令重新决策。

## 2. 控制、反制与首领

普通封印不是沉默一切。封物理、封法术、双封均保留合法道具、防御与保护；睡眠阻止主动行动。解封道具归为道具标签，被双封者可自解，睡眠者需要队友帮助。定心契为明确标注的自解例外。

命中判定采用技能基础命中、双方命中／抵抗和等级修正，最终概率在 UI 展示范围。范围封印低于对应单封的单目标命中；同档敌人不靠隐藏抗性临时改变结果。

原型反连续控制规则：任一硬控结束后，获得覆盖随后两次自身行动机会的“清醒”；期间不能再次受到硬控。硬控期间重复命中不能刷新剩余受控机会，也不得通过更换种类绕过，避免永远拖延到期而不触发清醒。普通减速和降防可以保留，但禁止叠加至无法行动的程度。敌我同类单位使用相同规则。

| 敌人类型 | 控制处理 | 封系的有效职责 |
| --- | --- | --- |
| 普通怪、比武角色 | 按技能完整生效，遵守清醒窗口 | 抢先封关键输出／治疗，配合点杀 |
| 精英 | 有明确可封阶段；硬控最多一次行动机会 | 打断准备、争取恢复与集火时间 |
| 首领本体 | 核心阶段不丢失整次行动，封印转为对应压制 | 截术降低下一次法术强度，锁锋降低下一次物理强度；入梦和震魄削弱下一次蓄力招 |
| 首领召唤物 | 按普通或精英标签处理，战斗前可查看 | 封住治疗怪、阻止召唤与保护技能 |

首领受到双封时，转为削弱下一次物理或法术攻击，只在首先发生的一次攻击结算，不同时生成两份压制。首领同类压制只刷新不叠加，结算一次适配攻击后消失；控制附带降防受减益上限限制。首版压制使对应下一次攻击伤害降低 20%，同类只取较强值；该比例仍需测试。禁止用三名封系让首领永久无法行动，也不能给全体副本敌人无提示的封印免疫。

睡眠与持续伤害、复活与行动顺序、休息与解封均在战斗日志可追踪，自动策略与手动使用同一规则。

## 3. 通用计算约定

以下为第一版可实现的数值模型，尚未验证最终平衡。角色基础成长与敌人模板需要在后续数值设计中补齐，不从这些公式反推已经存在的完整角色属性表。

### 3.1 基础值与伤害

A 为施术者当前物攻，M 为当前法攻，DP／DM 为目标当前物防／法防，H 为施术者治疗强度。先计入被动和有效属性增减，再处理招式明确的穿透。主修属性与功法成长详见门派设计。

```text
物理基础值 BP = max(1, A - 0.60 × DP)
法术基础值 BM = max(1, M - 0.55 × DM)
D物(c,f) = floor(c × BP + f)
D法(c,f) = floor(c × BM + f)
```

多段技能逐段计算，不先把系数相加后只扣一次防御。群攻逐目标计算，不自动按 T 平分伤害。需要穿透时先调整本次使用的目标防御，不把该穿透当作永久降防。

先按招式求原始伤害，再应用伤害提高、暴击、有效减伤和护盾。初版物理／法术暴击倍率为 1.5；固伤、毒、治疗和护盾默认不暴击，除非后续配置明确声明。各阶段用定点倍率并在最终损失气血前向下取整；无免疫时有效命中至少损失 1 气血，护盾仍可完全吸收。

同类百分比属性增益取较强值并刷新，不叠多层；同一属性百分比增益上限先设 30%，降防上限 30%，普通减伤上限 50%。门派明确的短时首领机制或剧情免疫另用标签，不能悄悄突破这些规则。

### 3.2 封印命中

```text
F(b) = clamp(
    b + 0.08 × S
      + 0.04 × (施术者封印命中值 - 目标封印抵抗值)
      + 1.00 × (施术者角色等级 - 目标角色等级),
    15, 85
) %
```

S 是该招式的关联功法等级，不是角色等级。b 是招式声明的基础百分点；命中和抵抗是属性值，不是百分比。例：同角色等级、命中抵抗相等、S=180、b=50，最终命中为 64.4%。清醒窗口和不可封阶段先作合法性检查，不在不可控目标身上消耗一次虚假的随机命中。物理招式的附带控制被免疫时，只跳过该控制效果，不取消本来合法的直接伤害；首领压制转换按对应规则处理。

双封、睡眠属于硬控，毒和单纯降防不属于硬控。震魄等物理招式附带的控制按招式主标签决定能否出手：封法术不会额外禁止一个合法物理招式的附带效果。

### 3.3 保护、恢复与持续状态

通用保护将被保护者本次可保护的直接伤害按 50% 分给保护者，另一半由原目标承担；以各自伤害份额分别应用个人减伤与护盾。原目标为多目标技能的一个目标时，保护者自己原有的一份群伤仍需结算，不被保护关系取消。毒、消耗气血成本和未标记可保护的特殊效果不能转移。

保护关系在下令阶段成立，保护者本回合主动行动被占用；倒地、睡眠等禁止保护状态出现时立即解除。一个目标只接受一名保护者，保护者不能再被另一条保护关系转移分担伤害，避免递归保护链。门派的守关为保护指令增强，不额外收取一次施法或真气。

治疗只能作用于存活目标，结算后不超过最大气血；复活使用独立效果，只对合法的在场倒地单位生效，不能复活已经换下场的宠物。治疗强度 H 不等同于法攻，固定恢复与百分比恢复需分别注明基数。

持续治疗和毒均记录来源、施加时参数快照、剩余结算次数。除明确规定的情况，不因施术者换装备或倒地而重新计算已施加状态。相同持续效果按门派规则刷新或保留强值，不能同时多结算一次。

### 3.4 行动标签与封印

普通攻击与物理招式受封物理限制；法术伤害、一般控制、恢复和增益受封法术限制。道具、防御、保护、召唤不属于这两类招式。睡眠和休息阻止主动操作；定心契等自解技能通过明确特例授权，不在通用逻辑里放开所有法术。

## 4. 原型需要验证的内容

1. 同等装备下，两回合内的点杀收益与面伤收益是否有合理差异；不能只比较爆发当回合。
2. 百骸谷的准备、爆发、休息和形态维持是否容易理解；状态剩余次数须始终可见。
3. 高速绛罗坊与降防绘契司是否各有队伍价值；清醒窗口是否仍允许有意义的控制配合。
4. 济世院即时治疗与照灯坊持续治疗是否分别有适用战斗；双辅助不能让所有战斗没有风险。
5. 固定伤害与毒是否受合理规则限制，同时保留高防敌人的对策价值。
6. 自动策略是否会误打睡眠目标、在血线不足时反复空放连击、在形态不足时选择兽相强招。
7. 复活、目标提前失效、资源不足与速度增益不能额外产生行动；休息不能被道具或自解技能绕过。
8. 五角色五灵兽的战斗时长、群攻与群疗覆盖、双方各十个单位时的指令效率；容量增加不能自动把所有群体技能改为全场生效。
9. 宠物归属唯一、主人倒地后宠物独立行动、旧宠离场指令取消和新宠下一回合行动；换宠不能额外获得行动次数或突破每人一只的上限。
