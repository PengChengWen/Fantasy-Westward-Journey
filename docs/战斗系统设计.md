# 战斗系统设计

版本：0.6 · 2026-10-19 · 设计规格，尚未实现。

门派驻地、35 个主动术式、七项专长与费用在 [门派设计](门派设计.md) 维护，本文件只维护通用规则。调整依据见 [独立设计调整说明](独立设计调整说明.md)。

## 1. 编成与回合

玩家最多五名角色，每人最多一只在场灵兽，共十个单位。灵兽记录主人 ID、实例 ID、本次入场 ID。角色和宠物分别获得一次原生行动；主人倒地或受控不自动使宠物失去行动。

召唤、换宠占主人行动，取消旧宠未执行指令，新宠最早下回合行动。水路、医签、回照和契约绑定实例与入场 ID，不继承给换入宠物。复活不补已失去的行动，不刷新真气、冷却、救援包或入场 ID。

回合阶段：回合开始 → 敌方承诺指令 → 玩家选择 → 校验与排序 → 逐行动结算 → 回合结束 → 胜负检查。敌方先根据公开状态承诺，之后不因玩家选招重算；上回合已施放的察机此时显示指定敌人本回合已承诺的指令类别与首目标，记录至本回合末。未侦察的普通敌人指令不公开，首领预告另按配置显示。目标失效时双方采用预先声明的替代规则。

速度排序使用提交结束时快照，同速用战斗随机流抽签。换序令在下回合排序后交换两名指定友军的位置，每队每回合最多一次；不交换指令、成本或行动次数。端点倒地、离场或被替换则取消交换。首领固定阶段行动不可交换，UI 提前提示。

## 2. 校验、成本与时间

按存活与失能、解锁、冷却、目标、资源、容量顺序校验，成功后一次支付。设施位满时只能显式选择替换自己的设施，不能挤掉队友设施。执行时目标失效，按技能预设改选合法同类目标或防御；不付原招成本，不给予第二次行动。

冷却 CD=c 的招式在 r 回合使用后，最早 r+c+1 回合再用。持续“3 回合”包括施放回合，至 r+2 回合末；“下回合”使用绝对回合号。刷新不得重复触发入场收益。主动术式至少研修到 1 级且满足技能表需求；专长 K=0 时不启用。

## 3. 统一数值

```text
B物 = max(1, 物攻 − 0.60 × 物防)
B法 = max(1, 法攻 − 0.55 × 法防)
D物(c,f) = floor(max(1, c × B物 + f) × 增减伤倍率)
D法(c,f) = floor(max(1, c × B法 + f) × 增减伤倍率)
```

f 缺省为 0。H 为施法时治疗强度，A 为物攻。倍率采用万分比整数，使用足够宽的中间值；每次伤害、治疗和护盾落账向下取整。初版普通直伤无随机浮动、无暴击；后续另定版本。治疗不超过缺失气血，护盾不算治疗。反馈、转移、待伤不触发吸血或额外攻击。

同类减伤取最高，不同来源乘算，总减伤上限 70%。护盾先扣最早到期；同来源刷新取较大剩余值，不相加；普通护盾总量不超过最大气血 50%。骨垒耐久不是普通护盾。普通攻击系数 1.0。

“总预算”只计算一次，再按各目标缺血比例分配，余数按稳定单位 ID 分配；满血目标不获得溢出收益。多目标伤害分别结算。门派公式中的次级分流使用主伤害减伤后、护盾前的数值，不递归。

## 4. 有限状态对象

| 对象 | 上限与期限 | 边界 |
| --- | --- | --- |
| 衡印 | 每施法者一个敌人、最多两枚、3 回合 | 换目标清旧印，消耗后归零 |
| 骨垒／幻饵 | 每队共享两个设施位 | 无行动、无宠物槽；骨垒可受指定攻击 |
| 骨片 | 每百骸角色最多两枚 | 敌人击毁设施不回收 |
| 水路 | 每队一条，两个不同存活同阵营端点 | 更新替换旧路，不递归 |
| 条件契约 | 每签主两份 | 同术式同目标不叠加，触发一次注销 |
| 医签 | 每医师三个不同目标 | 每目标全队最多一枚医签，不能多源叠签 |
| 待伤 | 每单位一笔，至下回合末 | 不能覆盖、延期或重新计算减伤 |
| 回照灯 | 每队两盏，每目标一盏 | 记录气血与储能独立，不回溯死亡／行动／资源 |

默认只能消耗自己创建的印、设施、契约、医签和灯；水路属于队伍公共对象。队友能否消耗必须由技能明确授权。同目标同来源刷新／替换，不靠反复施放突破容量。

同担约的一对端点占一份契约额度，角色与其宠物任一受击均消耗该份；宠物换出立即失效。绘契同目标可并存止戈约、缓济约两类契约，各占一份。契理学仅在未触发契约自然到期、且该敌人期间至少主动选择过一次规避条款的指令时生效，驱散、离场和主动兑现不返利。

医签在目标倒地时保留至原到期，以支持急援消耗该签；目标离场则注销。回照灯在目标倒地或离场时注销，不能借返照复活。察机记录只供绛罗术式判断，不给所有攻击附加隐藏伤害加成。

## 5. 伤害与反应顺序

合法目标 → 幻饵检查 → 基础直伤与减伤 → 骨垒或同担分担 → 缓释拆分 → 护盾 → 气血 → 倒地 → 根行动反馈。

一次伤害只能使用一种分担：优先骨垒，否则同担。分担受剩余耐久或伙伴剩余气血限制，伙伴最低保留 1 气血，不能分担的部分回到原目标。分担不再偏引、分担、缓释或触发合同。骨垒被指定攻击时使用建立时施法者防御快照承伤，耐久归零即拆除。

幻饵只偏引一个合法单体攻击的第一段，该段不扣气血，幻饵消失；不挡整次多段、群攻、持续伤害或剧情效果。不可偏引首领技能第一段减伤 20%；换幕额外减伤只作用于此类首段，遵守总上限，技能信息须预告。

待伤保存延后金额，到期绕过护盾扣气血，不再套防御或减伤。稳脉先偿还待伤，剩余治疗预算才补气血。医师离场、刷新、解控不能消债；目标倒地注销其待伤，复活不恢复该债。战斗结束清理战斗内待伤。

事件携带 rootActionId、来源实例、入场 ID、triggerDepth 与触发额度。反应不触发其他反应，各对象每次根行动最多触发一次。水路次级伤害不再分流、触发合同；合同反馈不再触发合同。实现时使用有限反应队列和异常断言，避免循环。

## 6. 控制与回合末

敌人可有明示的打断、沉默和持续伤害，七派核心不依赖双封和睡眠。打断最多取消一个行动机会，此后给予两个行动机会清醒；沉默保留普通攻击、防御和道具。首领免疫提前显示。

普通负面状态命中原型：clamp(基础命中 + 0.08S + 0.04×(命中属性−抵抗属性) + 等级差, 15, 85)%。友方自愿术式、明示必中的标记不使用该公式。失能仍消耗当次行动机会。

回合末依次为持续伤害、到期待伤、持续治疗、状态／设施到期、胜负判断；每步立即处理倒地。急援每施法者每战两包，不因复活或入场补充。削弱治疗类契约只修改对应预算，不取消复活本身。

## 7. 原型验收

先验证五人五宠与入场绑定，再加入标记／换序、设施、水路、契约、医签待伤、回照。每项覆盖成功、目标失效、容量已满、离场、回合边界。重点证明治疗预算守恒、换序不加行动、反应不递归、复活不刷新资源、敌方承诺不偷看玩家输入。

同版本、内容哈希、初始状态、指令和随机状态应复现相同结果；动画倍速、跳过和失焦不改变结算。当前仅有编队骨架，上述要求须随真实实现验收。
